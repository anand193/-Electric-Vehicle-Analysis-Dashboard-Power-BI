# ⚡ Electric Vehicle Analysis Dashboard – Power BI

## 📌 Project Overview
This project analyzes Electric Vehicle (EV) adoption trends using an interactive Power BI dashboard.  
The dashboard provides insights into vehicle growth over time, manufacturer performance, state-wise distribution, EV type share, and eligibility classification.

It is designed to help stakeholders understand EV market expansion and identify growth opportunities.

---

## 🎯 Business Objective
The goal of this dashboard is to:

- Track total registered electric vehicles
- Analyze EV growth by model year
- Compare BEV and PHEV adoption
- Identify top-performing manufacturers
- Understand state-wise EV distribution
- Analyze CAFV eligibility breakdown
- Identify most popular EV models

---

## 📊 Key Performance Indicators (KPIs)

- 🚗 Total Vehicles: **150.42K**
- 🔋 Average Electric Range: **67.83 km**
- ⚡ BEV Vehicles: **117K (78%)**
- 🔌 PHEV Vehicles: **34K (22%)**

---

## 🗂 Dataset Description
The dataset includes:

- Model Year
- Make
- Model
- Electric Vehicle Type (BEV / PHEV)
- Electric Range
- State
- City
- Electric Utility
- CAFV Eligibility Status

Data was cleaned and transformed using **Power Query**, and measures were created using **DAX**.

## 📈 Dashboard Features

### 🔹 Growth Analysis
- Total Vehicles by Model Year (trend analysis)
- EV adoption growth visualization

### 🔹 Geographic Analysis
- Total Vehicles by State (Map Visualization)
- Location-based filtering (City & Electric Utility)

### 🔹 Manufacturer Analysis
- Total Vehicles by Make
- Tesla leading market share
- Top-performing EV brands comparison

### 🔹 Vehicle Type Analysis
- BEV vs PHEV distribution (Donut Chart)
- CAFV Eligibility breakdown
- % share of total vehicles

### 🔹 Model-Level Analysis
- Treemap visualization of top EV models
- Model Y and Model 3 leading total registrations

---

## 🔍 Key Insights

- Battery Electric Vehicles (BEVs) dominate the market with 78% share.
- Tesla is the leading manufacturer in total EV registrations.
- Model Y and Model 3 are the top-selling EV models.
- EV adoption shows significant growth after 2018.
- Certain states show higher EV penetration compared to others.
- A large percentage of vehicles fall under CAFV eligibility categories.
